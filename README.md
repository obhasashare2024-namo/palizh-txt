## 📖 專案宗旨 (Project Mission)

正法白話漢譯善本是無數修行者與現代讀者直探佛陀根本教說、如實照見緣起與無常苦空的法身舍利。

歷代南傳大藏經漢譯本在流傳與排版過程中，大量殘留了巴利語特有的縮編符號（`Peyyāla`，如「……（中略）……」、「……」、「…」），導致讀者在閱讀關鍵之因緣論、戒相分別、阿羅漢成就偈與菩提分法時，頻繁遭遇語義斷崖。

**`palizh-txt` 專案以十二分精神與嚴格文獻學標準，完成了南傳大藏經（經藏、律藏、論藏三大藏共 30 個部派、近 7,000 篇經文正本）之全域語義無損擴增、0 STUB 徹底清零、中式引號「」與單引號『』100% 自然平衡閉合，以及底本印刷雜質（CBETA/大正藏比對註等）之純淨剝除，打造出當代最適宜機器學習語料訓練、數字化檢索與大眾隨身閱讀的現代白話善本。**

## 🔬 五道嚴格校勘門禁 (Verification Gates)

所有入庫正本均經過自動化語義校驗引擎與字節級實體驗證：
1. **0 STUB 門禁**：消滅所有「……（中略）……」、「……（中略）」、「……」、「…」縮編斷崖，100% 完整語義還原。
2. **標點與引號自然平衡門禁**：全藏雙引號「」與單引號『』100% 開閉對稱，修復歷史分卷遺留的孤立殘符。
3. **動態 Cleanad 雜質剝除門禁**：徹底清除古印本與排版軟件殘留的 CBETA 私注、大正藏跨典頁碼校註、無效參照括號。
4. **正本工作邊界唯一性**：嚴格限定純淨巴利白話中文（`.zh.txt`），精確排除音訊分卷（`_001` 等）與未切分混合包。
5. **雙向安全落盤與備份**：每篇修訂前強制留存歷史 `.bak`，杜絕任何文獻損壞。
